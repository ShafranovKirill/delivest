# Синхронизация корневого репозитория

- Рабочее дерево в корне проекта должно показывать актуальные для разработки `develop` подмодулей `server`, `client` и `agent`. После слияния задачи в `develop` подмодуля обнови соответствующий подмодуль в основном checkout проекта.
- Зафиксируй новые указатели подмодулей отдельным коммитом в корневом `develop` через ветку `codex/<краткое-имя>`. Проверь `git submodule status`, `git status` и доступность файлов в основном checkout. Не оставляй результат только в соседнем worktree подмодуля.
- Указатели подмодулей закрепляют конкретные коммиты. При публикации сначала должны быть доступны коммиты подмодулей, затем коммит корневого репозитория. Публикуй изменения только в рамках разрешённой пользователем задачи.
- Слияние в `main` и действия, запускающие релиз, требуют отдельной команды пользователя.
