# Delivest

## 2026-11-04 · Исправления по ревью

- Ручной откат Bastion читает Compose сохранённой ревизии после её восстановления. Проверка миграций обращается к запущенному PostgreSQL напрямую через Docker, поэтому сломанный текущий Compose ей не мешает.
- Список применённых миграций хранится вместе с подтверждённым выпуском. Повтор обновления сохраняет исходный список. При изменившемся или неизвестном списке старый образ не запускается. Для автоматического отката агент останавливает новый сервер и повторяет сверку под блокировкой таблицы миграций. Откат БД остаётся отдельной операцией.
- Настройки кухни и задание перепланирования фиксируются в одной транзакции. Воркеры одного филиала выполняются последовательно на текущей BEAM-ноде, читают актуальные настройки из БД и передают сбой в Oban для повтора.
- Следующая проверка на тестовой установке должна покрыть невалидный Compose, отказ readiness после миграции и восстановление совместимого выпуска. Результаты локальных тестов не заменяют этот прогон.
