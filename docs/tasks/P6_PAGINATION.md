## Приёмка

Первая часть P6 исправляет состояние URL и устойчивость страниц товаров:

- Порядок по умолчанию и пользовательские сортировки дополняются уникальным `id`; направления нормализуются после валидации Flop. Ошибочные параметры по-прежнему возвращают ошибку валидации.
- Поисковый фильтр перестаёт повторно сериализоваться вместе с `search` при переходах между страницами.
- Смена сортировки возвращает товары на первую страницу. Общая таблица определяет активную сортировку по первому полю, учитывая дополнительные поля для стабильного порядка.
- Доменные и LiveView-тесты проверяют границы 0/1/10/11, одинаковые значения сортировки, область филиала, переход на последнюю страницу, прямой URL, повторное открытие URL и сортировку.
