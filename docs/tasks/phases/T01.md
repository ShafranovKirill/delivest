# T01 — Владение общими сущностями и каталог

**Статус:** planned. **Источник:** [архив рефактора](../sources/refactor-spec.md), [архив функций](../sources/features-spec.md). **ID:** D01–D04.

## Цель и граница

Server catalog/products/categories/stops/cache/import plan; client только при необходимом изменении контракта.

## Зависимости и шаги

T00; ADR ownership и полномочий до миграции shared rows.

Развести global/branch операции, scoped stop keys и resume, фильтрацию preload, инвалидирование каждого затронутого филиала. Мигрировать shared rows с отчётом конфликтов.

## Приёмка и доказательства

Отрицательный role-тест; меню и кеш обоих филиалов; stop/resume B не меняет A; экспорт без чужого товара. Ранее 3 defect repro не являются доказательством исправления.

## Миграция и откат

Backfill и constraints поэтапно; предварительный отчёт конфликтов, мониторинг, rollback до удаления старой схемы.

## Следующий checkpoint

ADR и отдельный PR миграции; затем проверенный PR поведения. После проверенного PR обновить [handoff](../SESSION_HANDOFF.md) и [coverage](../COVERAGE.md) с SHA, командами и реальными результатами.
