## Миграция и откат

Owner-less address/checkout storage удаляется безопасно, выбор требуется повторить; session-owned guest выбор сохраняется при первом login. Миграция Order guest_session_access conservatively backfill-ит только legacy заказы без client_id. Старые linked guest заказы требуют входа по телефону. Downgrade возвращает прежний privacy риск; см. [решение и проверки](../S2_CHECKPOINT.md).
