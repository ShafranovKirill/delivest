# T06 — Долговечные эффекты и очереди

**Статус:** implemented-local; D10/R03/R04 проверены, production/live sandbox release gates остаются. **Источник:** [архив рефактора](../sources/refactor-spec.md), [архив функций](../sources/features-spec.md). **ID:** R03, R04, D10.

## Цель и граница

Server transactional outbox/Oban/queues и диагностика agent при необходимости.

## Зависимости и шаги

T00; T05 инварианты критического пути.

Сохранить side effect атомарно с доменным событием, разделить очереди по нагрузке, обработать retry/unknown outcome и D10.

## Приёмка и доказательства

Fault-injection: откат транзакции не публикует эффект, повтор не удваивает действие, очередь восстанавливается и backlog виден.

## Миграция и откат

Миграции 18–22: остановить intake, drain и остановить старые writers/consumers до upgrade. Расширенную схему и ledgers сохранять при откате; reader должен понимать несколько loyalty cycles. См. [проверенный порядок](../S3_RECOVERY_CHECKPOINT.md#порядок-поставки-и-отката).
