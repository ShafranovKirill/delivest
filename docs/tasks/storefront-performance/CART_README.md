## Как продолжить на другом устройстве

Получить `origin`, открыть `codex/storefront-bootstrap`, выполнить `git submodule update --init --recursive`, прочитать root `HANDOFF.md` и этот файл. Все нужные серверные и клиентские коммиты закреплены gitlink родителя; не подменять подмодули произвольными tip их develop. Затем открыть рабочие ветки подмодулей `codex/storefront-bootstrap`, проверив совпадение HEAD с родительскими gitlink.

Скрипт `server/scripts/cart_sql_measure.exs` защищён allowlist имён одноразовых БД `delivest_f01_demo_perf_before_20261119` (схема50, исходный сервер df1b349b) и `delivest_f01_demo_perf_after_20261119` (схема53, новая версия). Эти БД существуют только на текущем устройстве; их содержимое не отправляется в Git. На другом устройстве сначала подготовить одинаковые фикстуры. Никогда не запускать профиль на пользовательской/production БД.
