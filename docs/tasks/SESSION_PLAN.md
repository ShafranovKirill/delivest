## Экономный вход в контекст

Читать по порядку: [README](README.md) → этот план → короткий [handoff](SESSION_HANDOFF.md) → нужные строки [COVERAGE](COVERAGE.md) и разделы архивного ТЗ → целевые файлы кода. Не перечитывать всё ТЗ и аудит при каждом старте. Переиспользовать одного исследователя и исполнителя для связанных задач по правилам `AGENTS.md`; не дублировать уже проверенный поиск. Краткие записи путей, строк, решений и команд хранить в [MODULE_CONTEXT](MODULE_CONTEXT.md). После значимых изменений запускать целевые тесты; полный релевантный suite на gate блока и повторно только при новом изменении или конкретном риске. Перед каждой сессией легко сверить branch/SHA/status, без полного повторного аудита T00. Цепочку каждого F проверять just in time в его блоке/вертикали и сохранять краткую карту в MODULE_CONTEXT; полная F-матрица не gate перед S1.
