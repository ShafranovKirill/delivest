# P7 — общий dashboard

Реализация: [server PR №38](https://github.com/ShafranovKirill/delivest-ex/pull/38), commit `94bda1b7`, принят в `develop`. Root gitlink включает также принятую P6.

После входа обычного сотрудника без выбранного филиала открывается `/staff/dashboard`. В нём учитываются только разрешённые филиалы, независимо от устаревшего значения сессии. Выбор «Все филиалы» очищает сессию; явный `/staff/b/:slug/dashboard` показывает один филиал. Специальные входы кухни и курьеров сохранены.

Карточки, проблемные заказы, top‑5 товаров и последние восемь заказов используют одну область. Дата «сегодня» определяется отдельно в часовом поясе каждого филиала. Товарные агрегаты объединяются до выбора общего top‑5. Изменения прав обновляют данные, область и подписки открытой страницы.

Проверки: `MIX_TEST_PARTITION=p7_scope mix precommit` — 1472 теста, 0 ошибок, 7 исключены; compile warnings-as-errors, format, strict Credo прошли. Главный агент самостоятельно просмотрел diff, вернул замечания исполнителю и независимо повторил dashboard/branch URL/selector тесты после исправлений: 24 теста, 0 ошибок. CI серверного PR прошёл.

Проверены два разрешённых филиала и один чужой, stale session/reset/reload, разные локальные даты, общий товар ниже top‑5 каждого филиала, общий latest‑8 и отзыв доступа. Браузерный сценарий dashboard отдельно не запускался; маршруты, сессия и UI проверены LiveView-тестами. Независимый локальный прогон имел предупреждения исчерпания соединений при пересечении suites, но завершился без ошибок; дальнейшие параллельные прогоны используют `ERL_FLAGS='+S 4:4'`.
