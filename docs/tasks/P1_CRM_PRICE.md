# P1 — принятие цены CRM

[Server PR №41](https://github.com/ShafranovKirill/delivest-ex/pull/41) принят в `develop`.

В сверке Frontpad доступна кнопка «Принять цену из CRM». Действие заново читает каталог провайдера, проверяет показанную цену, права и филиальный CRM ID. Если цена изменилась, пользователь видит новую сумму и повторяет действие. CRM не изменяется.

Только цена товара, версия каталога и аудит записываются в одной короткой транзакции с блокировкой строки. Публикация аудита, cache invalidation и уведомления выполняются после commit. Совпадающая цена возвращает no-op. Результат сверки обновляется свежим каталогом в памяти; часовой refresh throttle сохранён отдельно.

Граница модели: цена shared-товара общая для всех филиалов. Действие для такого товара отключено и отклоняется сервером даже для администратора. Это сохраняет изоляцию выбранного филиала; автоматическое отделение товара или новая модель филиальных цен не вводились.

Проверки: первый полный `mix precommit` — 1482 теста, 0 ошибок, 7 исключены; compile/format/strict Credo прошли. После переводов и test-only изменений главный агент независимо выполнил domain/UI/MenuImport — 16 тестов, 0 ошибок. Серверный CI прошёл. Проверены stale snapshot, свежая цена/копейки, branch ACL, shared refusal, mapping race, no-op, ошибки CRM, неверные ID/цена и точный русский CTA. Перекрывающиеся вызовы проверены в SQL Sandbox с одним соединением; отдельная конкуренция двух DB-транзакций не измерялась. Браузерный provider-сценарий отдельно не запускался; UI покрыт LiveView-тестами, провайдер мокируется.
